# Aether Miner

A simple browser app for trying Aether mining on the public testnet.

Setup asks for nothing technical: a 12-word recovery phrase, a link to `aether-testnet-1`, then Scrypt on this computer’s CPU. **Balance** looks up a real `aether1` address on the explorer.

Practice finds stay on this computer. They are not paid onto the testnet. The recovery words restore this miner only. They are not a key that can spend Aether.

```bash
npm install
npm run dev
```

Open http://localhost:8080
