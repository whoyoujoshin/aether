# aether-client

Python client for the [Aether](https://github.com/whoyoujoshin/aether) chain: ML-DSA-44 keys, sending and receiving AETH, paid APIs (x402 `aether-memo` and `aether-prepaid`) and the on-chain service directory. It talks to a node's CometBFT RPC (port 26657) only.

```python
import os
from aether_client import AetherClient, Key, fetch_paid, find_services

client = AetherClient("http://localhost:26657", "aether-testnet-1")
key = Key.from_mnemonic(os.environ["AETHER_MNEMONIC"])  # same address as `aetherd keys add` / `agentmcp`

sent = client.send(key, "aether1...", "0.5 AETH", memo="invoice-42")
done = client.wait_for_transaction(sent.hash)            # confirmed | failed | pending (timeout)
# Retrying after an error: client.rebroadcast(sent.signed) -- never a second send().

res = fetch_paid(client, key, "https://api.example.com/forecast", max_amount="0.05 AETH", prepay="1 AETH")
services = find_services(client, query="weather", max_price="0.1 AETH")
```

Amounts always carry a unit (`"1.5 AETH"`, `"1500000uaeth"`). Tests: `python -m unittest discover -s tests` (checked against `../testdata/vectors.json`, generated by the Go code).
