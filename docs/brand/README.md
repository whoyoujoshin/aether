# Aether primary identity

**These are the only logos and marks to use going forward.** Do not invent
alternate Æ marks, wordmarks, or colorways without updating this sheet.

Source: `aether-primary-identity.pdf` (canonical). Raster/SVG exports are
derived from that file for convenience.

## Palette

| Token | OKLCH | Role |
|---|---|---|
| ink | `oklch(0.22 0.01 60)` | Primary glyph / text |
| bone | `oklch(0.95 0.012 85)` | Background |
| signal | `oklch(0.58 0.16 32)` | Middle bar of Æ (color mark only) |

One-ink and reversed lockups drop signal to full ink / full reverse.

## Rules (from the sheet)

- Æ is a five-part grid: two diagonals + three bars; diagonals share one apex bar.
- Bar height 14u, stem 16u.
- At 16px favicon size, thicken bars and render signal as full ink.
- Æ doubles as the currency symbol (e.g. Æ248.10).
- Prefer the horizontal lockup (Æ | Aether) or stacked AETHER wordmark from this sheet.

If you need SVG/PNG cuts of the mark alone (favicon, app icon, wordmark), ask —
export from this PDF rather than redrawing.
